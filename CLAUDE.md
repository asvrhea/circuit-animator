# Circuit Animator

Browser app: race-circuit screenshot (or KML/GPX) → extracted track → lap animation → video export.
Vite + TypeScript + Canvas 2D, Vitest. Client-side only. No UI framework.

- Always follow the `circuit-animator` skill (phases, layout, model routing, token rules).
- Current state lives in `PROGRESS.md`. Read it at the start of a session instead of exploring.
- Commands: `npm run dev`, `npx vitest run --reporter=dot`, `npx tsc --noEmit`, `npm run build`.
- No F1/team logos, names or trademarked graphics.
